# BC Residential Tenancy Act — Multilingual Translations

[![License: CC0-1.0](https://img.shields.io/badge/License-CC0_1.0-lightgrey.svg)](LICENSE)

Google Translate versions of the **British Columbia Residential Tenancy Act (RTA)** — [SBC 2002, c. 78](https://www.bclaws.gov.bc.ca/civix/document/id/complete/statreg/02078_01) — for tenants in BC whose first language is not English.

Produced using the **Google Translate** button built into the Chrome/Edge browser on the official BC Laws full-text page.

---

## Why this exists

Many renters in British Columbia speak little or no English. Bad landlords count on that. The **BC Residential Tenancy Branch (RTB)** handles disputes between landlords and tenants, but the law itself is only officially published in English. This repo makes it easier for tenants to read and understand their rights before — or during — an RTB arbitration hearing.

> If you are being harassed, illegally evicted, or having illegal rent increases imposed by your landlord in BC, you can file a dispute with the **Residential Tenancy Branch**: <https://www2.gov.bc.ca/gov/content/housing-tenancy/residential-tenancies/solving-problems/dispute-resolution>
